# Архитектура

## Принципы

- **Без сборки и зависимостей.** Браузер грузит файлы как есть. Нет npm, бандлера, фреймворка.
- **Классические скрипты, общий глобальный scope.** Все `js/*.js` подключены обычными `<script src>`
  (не модулями). Функции и `let/const` верхнего уровня видны из всех файлов и из инлайновых
  `onclick="..."` в HTML-строках. Поэтому имена должны быть уникальны на весь проект.
- **Русские идентификаторы данных.** Поля базы и многие функции названы по-русски
  (`остаток_г`, `цена_упаковки`, `нормыУслуги`). Это осознанно — так данные читаются колористом.
  Новый код пишется в том же стиле.
- **Один источник правды — объект `DB`** в памяти, зеркало в `localStorage['colorist_v7']`.

## Порядок подключения скриптов

```
core → costing → store → parser → stock → services → works → expenses → report → settings → sync → app
```

На этапе загрузки файлы только объявляют функции и константы; код, который что-то *делает*,
есть лишь в `app.js` (запуск). Поэтому порядок жёстко важен в одном месте: **`app.js` последним** —
там `TABS` ссылается на `renderStock`, `renderServices`… и сразу вызывается `load()` и `go('stock')`.
Остальной порядок — для читаемости (от фундамента к экранам).

Если в новом файле на верхнем уровне вызывается функция из другого файла — тот должен стоять выше.

## Как рисуется экран

Рендер — строки HTML через шаблонные литералы, без виртуального DOM:

```
go(tab)                      app.js
  ├─ TABS[tab].r()           render-функция цеха → строка HTML
  ├─ #view.innerHTML = …
  └─ #fabWrap.innerHTML = fabFor(tab)   нижняя кнопка действия
```

- Перерисовка = заново вызвать `go(TAB)` или конкретную render-функцию. Состояние форм при этом
  теряется, поэтому формы держат черновик в глобальной переменной (`_nw`, `_inc`, `_seНормы`).
- Любые всплывающие формы — **шторка** `openSheet(title, bodyHtml, footBtns[])` из core.js.
  Одна на всё приложение: открыть новую = заменить содержимое.
- Подтверждение — `confirmDo(msg, onYes, yesLabel)` (нативный `confirm()` не используется:
  блокировался в песочнице артефакта, где приложение начиналось).
- Уведомления — `toast(msg)`.
- Пользовательский текст в HTML **всегда** через `esc()`.

## Состояние UI (глобальные переменные)

| Переменная | Файл | Смысл |
|---|---|---|
| `DB` | store | вся база |
| `TAB` | app | текущая вкладка |
| `_monthOff` | core | сдвиг календарного месяца (0 = текущий, −1 = прошлый); общий для Работ/Расхода/Отчёта |
| `_wPeriod`, `_expPeriod`, `_repPeriod` | works/expenses/report | `'month'` или `'all'` |
| `_stockOpen`, `_stockQuery` | stock | раскрытые группы склада, строка поиска |
| `_inc` | stock | черновик «Приход списком» (живёт между открытиями) |
| `_nw` | works | черновик мастера расчёта работы |
| `_seIcon`, `_seНормы`, `_seБезОбщих` | services | черновик редактора услуги |
| `_sync` | sync | статус синхронизации |

## Поток данных

```
действие пользователя
   → мутация DB (в функциях saveX / doX)
   → save()                         store.js: DB._updatedAt = now; localStorage; scheduleSync()
   → через 2 с pushSync()           sync.js: PUT /data {updatedAt, db}
   → go(TAB) / closeSheet() / toast()

старт приложения
   → load()  → мигрируй()           store.js
   → go('stock')
   → pullSync()                     сервер свежее → заменить DB целиком; локально свежее → push
```

Данные, пришедшие извне (сервер, файл копии), всегда прогоняются через `мигрируй()`.

## Ключевые доменные понятия

- **Материал** (весовой) — краска/оксид/порошок/смывка/уход, учёт в граммах, цена за грамм =
  `цена_упаковки / нетто_г`.
- **Услуга** — строка прайса (вилка цены и времени) + типовой расход (нормы).
- **Работа** — факт оказания услуги: строки расхода материалов (списываются со склада),
  снимок норм, цена, себестоимость, маржа.
- **Нормы расхода** — то, что не ведётся на складе (шампунь, маска, «мелочь»), считается
  по средней цене и идёт только в себестоимость.
- **Расход** — денежный журнал трат. Закупки материалов попадают сюда автоматически из Прихода.
- **Маржа** (работа) = цена − себестоимость. **Прибыль (касса)** (отчёт) = выручка − все траты.
  Это разные метрики, их не смешивать.

## PWA

- `sw.js`: network-first — сначала сеть (чтобы подтягивать обновления), офлайн — из кэша.
- Регистрация SW только на `https:`.
- `navigator.storage.persist()` просит браузер не чистить хранилище.
