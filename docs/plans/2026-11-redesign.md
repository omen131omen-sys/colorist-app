## 1. Оболочка «стекло» вместо старой

Источник — `demo/skin.{html,css,js}` (концепт 30.10: матовое стекло поверх прядей, мокко, Jost + Manrope).
Главные экраны рисует оболочка из `DB`, формы (работа, приход, материал, услуга, трата, нормы,
оборудование, заказ) — функции цехов в стеклянной шторке.

- `index.html` ← разметка `skin.html` + мета PWA; `css/app.css` ← стиль оболочки;
  `js/app.js` ← оболочка без демо-частей. Порядок цехов не меняется, `app.js` — последним.
- Добавить, чего нет в демо:
  - экран «Настройки» (шестерёнка в шапке) — `renderSettings()`: версия, сервер, копии, нормы, сброс;
  - запуск: `pullSync()`, регистрация `sw.js`, `navigator.storage.persist()`;
  - убрать бейдж «демо», демо-меню, демо-приветствие.
- Маржа как в старом отчёте: только работы с `MARG_FROM` (`margCounted`). В карточке работы до этой
  даты — без себестоимости и маржи (в августе их не считали — иначе «маржа 100%»).
- Старые `render*` экранов в цехах пока остаются (не вызываются) — чистка отдельным шагом.
- Демо (`demo/`) не трогаем; позже перевести его сборку на рабочую оболочку.

## 2. Читаемость (главная жалоба)

Замер на экране 390 px: подписи 10–12 px цветом с прозрачностью 0.6, стекло 30 % поверх полосатого
фона, цифры Jost 200–300 в мелких размерах.

Правила:
- Текст — сплошными цветами из `:root`, без прозрачности: основной `--ink`, второстепенный `--ink-2`
  (контраст ≥ 4.5:1 на реальном фоне карточки), декоративный `--ink-3` — только не для смысла.
- Размеры: основной ≥ 14 px, подписи ≥ 12.5 px, подписи вкладок ≥ 11.5 px; капс-надписи — ≥ 12 px.
- Стекло под текстом — заливка ≥ 0.62; пряди видны в фоне и по краям, а не сквозь буквы.
- Jost 200 — только крупные суммы (≥ 40 px); меньше — 300–400.
- Тёмные карточки: второстепенный текст ≥ 0.78 непрозрачности.
- Проверка — контраст, посчитанный по пикселям скриншота под текстом, а не на глаз.
- Цвета — переменными в `:root` (правило проекта).

## 3. Шрифты в приложении

Jost и Manrope (кириллица + латиница, woff2) — в `fonts/`, подключение `@font-face`, файлы в `ASSETS`
`sw.js`. Без интернета и без Google.

## 4. «Хватит примерно на …» (из разговора 08.11)

- `хватитДней(m, works, сегодня)` в `costing.js`: расход материала (`факт_граммы` и `факт_оксида`)
  за последние 60 дней ÷ дни → сколько дней хватит остатка. Нужно ≥ 2 использований в окне, иначе `null`.
- Подпись: «≈ N дн» (< 14), «≈ N нед» (< 9 нед), «≈ N мес», «больше года»; 0 г — «закончился».
- Где: карточка на складе (под граммами), шторка материала (вместо «работ хватит»).
- Тесты в `tests/`.
