# Цех «Ядро» — [js/core.js](../../js/core.js)

Инструменты, которыми пользуются все экраны. Не знает про конкретные сущности.

## Справочники
- `TYPE` — типы материалов и их подписи; `TYPE_BADGE` — цвет бейджа.
- `LEN`, `DEN`, `LEN_K`, `DEN_K` — длина/густота волос. **Сейчас не используются** (остаток матрицы
  расхода по длине/густоте), см. [issues.md](../issues.md).

## Деньги и id
- `money(v)` → «1 240 ₽» (целые), `money1(v)` → с одной десятой.
- `uid(p)` → префикс + 6 случайных символов.

## Иконки
- `LINE_ICONS` — иконки групп склада, `gico(k)` — кружок с иконкой.
- `SVC_ICONS`, `SVC_ICON_KEYS` — набор для услуг; `svcSvg/svcCircle/svcInline(s)` — по `s.иконка`
  (по умолчанию «капля»).

## Периоды
Месяц — **календарный** (1-е…последнее), не скользящие 30 дней.
- `W_PERIODS` — `[['month','Месяц'],['all','За всё время']]`.
- `_monthOff` — общий сдвиг месяца для всех экранов; вперёд дальше текущего нельзя.
- `periodRange(p)` → `{from, to}`; `inPeriod(дата, p)`; `monthLabel()`.
- `monthNav(rerenderName)` — стрелки ‹ месяц ›; `shiftMonth(step, rerender)`.
- `periodShowing(дата, текущий)` — если запись вне текущего фильтра, перелистывает на её месяц
  (иначе свежая запись задним числом «пропадала»).

## Даты
Все даты — строки `YYYY-MM-DD` в **локальном** поясе (`isoLocal`, `todayISO`) — `toISOString()`
сдвигал дату через UTC.
- `fmtDay` «1 сентября», `fmtDate` «1 сен», `fmtDateFull` «1 сентября, пн [2025]».

## Форматирование
- `esc(s)` — экранирование для HTML (обязательно для пользовательского текста).
- `fmtG(g)` — граммы с одной десятой. `plural(n, 'работа','работы','работ')`.
- `emptyBox(эмодзи, заголовок, текст)` — заглушка пустого списка.
- `deepc`, `blankMatrix` — **не используются**.

## UI-примитивы
- `openSheet(title, bodyHtml, footBtns[])` / `closeSheet()` — нижняя шторка (на ≥800px — модалка).
  Пустой `footBtns` прячет подвал. Пока шторка открыта, FAB скрыт.
- `confirmDo(msg, onYes, yesLabel='Удалить')` / `closeConfirm()` / `doConfirm()`.
- `toast(msg)` — 1.8 с.
