# Цех «Экономика» — [js/costing.js](../../js/costing.js)

Сердце продукта: откуда берётся себестоимость и маржа. Чистая логика, без DOM.

## Формулы

```
цена за грамм         gpr(m) = m.цена_упаковки / m.нетто_г
сумма нормы           нормаСумма(n) = кол × цена × (1 + накидка/100)
себестоимость работы  calcCost(w) = Σ шаги: факт_граммы × gpr(материал)
                                  + Σ шаги: факт_оксида × gpr(оксид)      (легаси)
                                  + Σ штучные: кол_во × цена_за_штуку      (легаси)
                                  + Σ нормы (снимок): нормаСумма
                      → округление до рубля
маржа                 цена − себестоимость
```

Себестоимость считается по **текущей** цене материала на момент сохранения работы и
**сохраняется** в работе. Поменялась цена позже — старые работы не пересчитываются (так задумано).
Нормы в работе — снимок (`снимокНорм`) с ценой, по той же причине.

## Светофор маржи — `margLevel(marg, price)`
- `< 0` → красный «в минус»
- `< 45%` от цены (`AMBER_MARGIN`) → жёлтый «низкая маржа»
- иначе зелёный

## Граница честной маржи — `MARG_FROM = '2026-09-01'`
Августовские работы вносились задним числом без формул → себестоимость 0, маржа 100%.
`margCounted(w)` исключает их из всех расчётов маржи; выручка и количество считаются как обычно.

## Нормы расхода
- `ЕД` — `г`, `шт`, `раб` (за работу).
- `нормыПоУмолчанию()` — стартовый справочник.
- `ТИПОВОЙ_РАСХОД` — регэкспы по названию услуги → нормы; используется **один раз** миграцией.
  Третий элемент `true` = `без_общих`.
- `нById(id)`, `нормыУслуги(s)` — свои нормы услуги + общие (`всем`), если не `без_общих`.
- `снимокНорм(list)` — заморозить нормы с ценами для записи в работу (строки с `кол=0` выпадают).

## Списание
- `спис(шаг)` / `списШт(p)` — сколько реально ушло со склада (у старых записей поля нет → запрошенное).
