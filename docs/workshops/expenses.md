# Цех «Расход» — [js/expenses.js](../../js/expenses.js)

Вкладка «Расход»: денежный журнал трат + оборудование.

## Траты
- `renderExpenses()` — период (`_expPeriod`), сумма, чипы по категориям, подсказка, список по дням.
- Категории `EXP_CATS`; вручную доступны `EXP_MANUAL_CATS` (всё, кроме «материалы»).
- Закупки со склада (`категория='материалы'` и `материал_id`) помечены «со склада», не редактируются.
- `editExpense(id)` / `saveExpense(id)` — сумма, дата, категория, заметка.
- `delExpense(id)` — для закупки **откатывает склад** (`граммы`, у старых записей — из заметки
  «… · 2 уп.») и **цену** (если с тех пор её не переписал другой приход). Не уводит остаток в минус.

## Оборудование
`equipSheet()`, `editEquip`, `saveEquip`, `delEquip`, `equipTotal()` — список вложений (фен, утюжок…),
в Отчёте как «Вложено в оборудование», в прибыль не входит.

## Связи
- Запись закупок — `logPurchase()` в [stock.md](stock.md).
- Нормы расхода (шампунь, мелочь) сюда **не попадают**: деньги учитываются при покупке,
  нормы — только в маржу.
