# Цех «Сервер» — [server/](../../server/)

## Что есть в проекте
- [server/onecommand.txt](../../server/onecommand.txt) — одна команда: ssh на сервер и запуск
  установщика, зашитого в base64.
- [server/install-nginx.sh](../../server/install-nginx.sh) — тот же установщик в читаемом виде.

Установщик (для сервера, где 80/443 уже занимает nginx):
1. Домен из IP: `<IP>.sslip.io` (запасной — `<IP>.nip.io`).
2. Отключает Caddy.
3. Сайт nginx `colorist`: `proxy_pass http://127.0.0.1:8787`, `client_max_body_size 20m`.
4. certbot → HTTPS с редиректом.
5. Ключ берёт из `/etc/systemd/system/colorist-sync.service` (`Environment=KEY=…`), проверяет
   `https://<домен>/health`, печатает адрес и ключ для приложения.

## Чего в проекте НЕТ
**Исходника самого сервиса синхронизации** (`colorist-sync`, порт 8787) и его unit-файла. Он живёт
только на сервере. Если сервер умрёт — восстанавливать не из чего. Первое дело — забрать его в
проект (`server/sync/`), см. [issues.md](../issues.md).

Контракт, который сервис обязан выполнять, описан в [sync.md](sync.md#протокол-с-сервером).

## Безопасность
- Ключ — единственная защита, передаётся в заголовке `X-Key`, на клиенте хранится в localStorage.
- `onecommand.txt` содержит IP сервера, пользователя и путь к ssh-ключу — не публиковать вместе с сайтом.
