# Цех «Услуги» — [js/services.js](../../js/services.js)

Вкладка «Услуги» — прайс-лист. Рецепт в услуге **не хранится**: формула у каждого клиента своя
и вставляется при расчёте работы.

## Экран
- `renderServices()` — карточки: иконка, название, вилка цены, «N работ · ср. чек», маржа % по факту.
- `svcStats(s)` — факт из журнала: количество, выручка, средний/мин/макс чек; маржа только по
  работам с `MARG_FROM`.
- Вилки: `svcFrom/svcTo` (цена), `svcTimeTo`, `svcPriceText`, `svcTimeText`, `fmtHrs`.

## Карточка — `svcSheet(id)`
Цена, время, «выходит в час» (худший расклад: мин. цена / макс. время — лучший: макс. / мин.),
типовой расход с итогом, факт по журналу, кнопка «▶️ Провести работу» → `newWork(id)`.

## Редактор — `editService(id)` / `saveService`
- Название, иконка (`pickSeIcon`), цена от/до, время от/до, примечание.
- Перепутанные «от/до» меняются местами; равные → фиксированная цена.
- Типовой расход (`drawSeНормы`, `svoiHtml`, `setSeНорма`): показаны все нормы справочника,
  0 = не используется. Общие (`всем`) — одной галочкой (`_seБезОбщих`).
- `delService(id)` — работы не удаляются (у них есть `услуга_назв`), но см. баг с правкой таких
  работ в [issues.md](../issues.md).
