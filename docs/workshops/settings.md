# Цех «Настройки» — [js/settings.js](../../js/settings.js)

Открывается шестерёнкой в шапке (в таббаре вкладки нет).

## `renderSettings()`
1. Версия приложения (`APP_BUILD`).
2. Синхронизация: статус, «Синхронизировать» / «Отключить», или форма адрес + ключ → `connectSync()`
   ([sync.md](sync.md)).
3. Нормы расхода → `нормыSheet()`.
4. Резервная копия: «Отправить» (share), «Скачать», «Восстановить из копии».
5. Опасная зона: «Удалить все данные» → `resetData()` — заменяет базу пустым `seed()`; при подключённом
   сервере `syncReplaceNext()` стирает данные и там (подтверждение об этом предупреждает).

## Справочник норм
`нормыSheet()`, `editНорма(id)`, `saveНорма(id)`, `delНорма(id)`.
Удаление нормы чистит ссылки в услугах, но **не трогает работы**: у них снимок с ценой, прошлая
маржа не должна меняться.
