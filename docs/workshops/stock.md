# Цех «Склад» — [js/stock.js](../../js/stock.js)

Вкладка «Склад»: весовые материалы в граммах.

## Экран
- `renderStock()` — строка поиска + `#stockBody`; `renderStockBody()` перерисовывается отдельно
  при поиске и раскрытии групп (чтобы не терять фокус в поиске).
- Плашка «N на исходе» → `orderSheet()`.
- Группы по типу (аккордеон `accHeader`, состояние `_stockOpen`, по умолчанию открыта «Краска»).
- `sortMats()` — краски как в палитре: уровень 10→1, корректоры `0.xx` в конце, тон как строка
  (6.2 < 6.21 < 6.32 < 6.4); оксиды по проценту; остальное по алфавиту.
- `stockState(m)` — Мало (≤ мин) / Заканчивается (≤ 1.5× мин) / В норме.
- FAB: «📥 Приход списком» + «＋» (новый материал).

## Карточка и правка
- `matSheet(id)` — все параметры, цена за грамм, стоимость остатка.
- `editMaterial(id)` → `matKind('w', m)` — форма; `autoNet()` прикидывает граммы из мл по `DENSITY`
  (краска 0.93 — по замеру тюбика, оксид 1.05). Ручной ввод граммов не перетирается.
- `saveMaterialW(id)`, `delMaterial(id)`. После сохранения группа раскрывается, поиск сбрасывается.

## Приход одной позиции — `restockMat` / `doRestockMat`
- Упаковки × нетто → граммы; сумма / упаковки ≠ цене → новая `цена_упаковки` (разница ≥ 1 ₽).
- Дата покупки (задним числом — трата ляжет в тот месяц), галочка «В расход».
- Поле «поправить граммы без денег» (±) — корректировка без траты; приоритетнее прихода.
- Трата пишется через `logPurchase()` с `граммы`, `цена_до`, `цена_после` — для отката.

## Приход списком — `incomingSheet` / `doIncoming`
Черновик `_inc = {text, rows, дата, вРасход}` живёт между открытиями: можно закрыть, завести
недостающий материал и вернуться.
1. Вставить текст → `incParse()` → `parseIncomingText()` ([parser.md](parser.md)).
2. Сверка строк: жёлтая = несколько кандидатов, красная = не распознано.
   `incSet()` при смене материала/упаковок пересчитывает граммы и сумму, **если их не трогали руками**
   (`_gТронут`, `_sТронут`).
3. Предупреждение о скачке цены > 1.5× — почти всегда другая фасовка.
4. `doIncoming()` — проводит готовые строки, неготовые остаются в черновике.

## «Заказать» — `orderSheet` / `copyOrder`
Позиции с остатком ≤ минимума, кнопка копирует список для поставщика. `withBrand()` добавляет бренд,
если его нет в названии.

## Штучные (`pieces`)

**в интерфейсе не достижим**: штучные нигде не выводятся, а переключателя вида в форме материала нет.
