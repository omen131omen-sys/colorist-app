# Цех «Хранилище» — [js/store.js](../../js/store.js)

- `seed()` — пустая база (демо-данных нет; данные приходят из копии или с сервера).
- `APP_BUILD` — версия сборки, видна в Настройках. **Поднимать при каждой выкладке.**
- `KEY = 'colorist_v7'` — ключ localStorage. Смена ключа = «потеря» данных у пользователей, не трогать.
- `load()` — прочитать, при отсутствии создать `seed()`, прогнать `мигрируй()`.
- `мигрируй()` — приведение к текущему формату, список шагов в [data-model.md](../data-model.md#миграции-мигрируй-в-storejs).
- `save()` — `DB._updatedAt = Date.now()`, запись в localStorage, `scheduleSync()`.
  Вызывать после **каждой** мутации DB.
- `mById`, `pById`, `sById` — поиск материала, штучного, услуги.

## Правила
- Данные извне (сервер, файл) — только через `мигрируй()`.
- `localStorage` ограничен ~5 МБ; сейчас база ~80 КБ, запас большой, но фото/вложения туда класть нельзя.
