# Цех «Работы» — [js/works.js](../../js/works.js)

Вкладка «Работы»: журнал оказанных услуг и мастер расчёта.

## Журнал — `renderWorks()`
- Период: месяц (стрелки) / всё время (`_wPeriod`, `setWPeriod`).
- Сводка: выручка, маржа (только `margCounted`).
- Группировка по дням, карточка: услуга, первая строка формулы, цена, маржа со светофором,
  бейдж «задн. числом».
- `workSheet(id)` — детали, себестоимость, маржа, `copyRecipe()` — рецепт для DIKIDI.

## Мастер «Расчёт работы»
Черновик `_nw = {услуга_id, lines, штучные, нормы, остаток, формула, цена, время, _date, _noStock,
_editId?, _origByMat?}`.

1. `newWork(svcId)` → `loadNwLines()` — из услуги берутся цена «от», время, нормы.
2. Вставить формулу → `parseFormula()` → `parseFormulaText()` ([parser.md](parser.md)).
3. Сверка строк (`drawNewWork`): выбор материала, граммы, предупреждение о нехватке (`availFor`).
4. `нормыБлок()` — типовой расход: правка количества, удаление, «вернуть».
5. Цена, время → `recalcNw()` — итог: материалы, нормы, себестоимость, маржа, предупреждения.
6. `saveWork()`.

### Сохранение — `saveWork()`
- Правка: сначала **вернуть на склад** старую работу (если списывалась), удалить её, затем сохранить
  новую под тем же id.
- `себестоимость = calcCost(...)`, `маржа = цена − себестоимость`.
- Если не «задним числом»: списание `списано = min(запрошено, остаток)`; остаток не уходит в минус.
- Переключает фильтр на месяц работы (`periodShowing`).

### Правка — `editWork(id)`
Собирает `_nw` из работы. `_origByMat` — граммы, уже списанные этой работой, чтобы `availFor` не
считал их нехваткой. `_svcName` — название услуги из работы: если услугу удалили из прайса,
в списке она показана как «(удалена из прайса)», и работа сохраняется под прежними id и названием.
`saveWork()` проверяет услугу **до** любых изменений базы.

### Удаление — `delWork(id)`
Возвращает на склад `спис(шаг)` (а не запрошенное) — только если работа списывалась.

## «Задним числом» (`без_склада`)
Склад не трогается ни при сохранении, ни при удалении. Для переноса старых записей.
